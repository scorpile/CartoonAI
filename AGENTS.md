# Cel Studio

Para producir o continuar una caricatura, lee `skills/cartoon-production/SKILL.md`. Para cambiar el software, el motor es `celstudio/v2/` (formato en `docs/FORMATO_V2.md`, guía en `docs/ESTUDIO_V3.md`) y ejecuta `python -m pytest tests -q`.

No introduzcas modelos de video ni audio en el flujo actual. No distribuyas herramientas propietarias ni credenciales dentro del proyecto. Documenta el alcance real de cada adaptador. El motor v1 se archivó fuera de este repositorio.

Para usar la app desde un agente hay un servidor MCP (`python -m celstudio.mcp`, ver `docs/INSTALACION.md`).

Documentación en inglés: `README.md`, `docs/en/FORMAT.md`, `docs/en/ENGINE.md`.
